# OCR Text Extractor

A Flask portfolio project that extracts text from screenshots and images using your existing PaddleOCR implementation.

## Features

- Upload PNG, JPG/JPEG, BMP, TIFF, and WEBP images (up to 10 MB).
- Preview the selected image before processing.
- Extract text and edit the result in the browser.
- Copy the text or download a UTF-8 `.txt` file.
- Save each extracted result in `output/`.
- Responsive layout and basic upload validation.

## 1. Install PaddleOCR and PaddlePaddle

`pytesseract` is a Python wrapper; it does not install the Tesseract executable itself.

PaddleOCR is installed as a Python package with its PaddlePaddle runtime. Installation can be platform- and Python-version-sensitive, so use a supported Python version and follow the official PaddleOCR/PaddlePaddle installation guidance for your operating system. The existing service is configured for English (`lang="en"`).

## 2. Create a virtual environment

Windows:

```powershell
py -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## 3. Run locally

```bash
python app.py
```

Open `http://127.0.0.1:5000/` in your browser. For Flask debug mode, set `FLASK_DEBUG=1` in your local environment; do not enable debug mode in production.

## Result files and privacy

Extracted text files are written to `output/` using unique filenames. The UI provides a download link for the result generated by the current request. The uploaded image is removed after OCR processing. Result text files remain on disk until manually deleted; `output/*.txt` is excluded from Git.

## Deployment notes

- Set a strong `SECRET_KEY` environment variable.
- Configure the Tesseract executable and language data in the deployment environment.
- Use a production WSGI server; do not use Flask's development server in production.
- Consider a scheduled cleanup policy for old result files if the application is publicly hosted.
- This project uses local PaddleOCR; OCR accuracy depends on image quality, text orientation, and language data.

## Troubleshooting

- **PaddleOCR/PaddlePaddle installation errors:** Confirm that your Python version and operating system are supported by the installed PaddlePaddle wheel, then reinstall using the compatible instructions.
- **No text detected:** Try a sharper, higher-resolution screenshot with good contrast.
- **Indonesian text is inaccurate:** Install Indonesian language data and configure the OCR language as described above.
